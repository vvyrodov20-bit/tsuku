# Платёжные профили по странам

Версия 5, 14 октября 2026. Полный справочник для 111 GEO сайта.

Страна выбирается по GEO или вручную. Язык влияет на подписи и инструкции, но не подменяет страну. Подписи переводятся на 42 языка, торговые названия сохраняются.

Это справочник местных способов оплаты, а не данные кассы конкретного аккаунта 1win. Первичные источники подтверждают существование региональных систем; они не подтверждают их подключение у этого оператора. На странице это уточняется рядом со списком. При отсутствии подтверждённого местного бренда оставлены банковский перевод/карты. Неизвестный GEO не получает российский список по умолчанию. Криптовалюта не считается автоматически доступной во всех странах. Кассовые ваучеры не используются в списках вывода.
